# Решётка трубы: ограниченный сценарий v002

Один Node.js CLI сохраняет фактически использованный собственный алгоритм
решётки: разбиение по фасетам и профилям, смещённые профили, общие вершины,
замкнутый quad mesh. Зависимости — только встроенные модули Node.js.
Проверенный runtime: Node v22.17.1. Это сценарий одного объекта, не общий адаптер.

```powershell
node technical_library/mesh_audit/pipe_lattice/lattice.cjs --source <absolute-source.json> --reference <absolute-mesh_gap_allowance.json> --output-directory <absolute-new-directory>
```

`scenario.json` фиксирует метры, ось, 18 секторов, 16 полурядов, толщину/отступ
и SHA256 двух приватных входов. Вход — 126 упорядоченных строк
`{i,pos:[x,y,z]}`: семь колец по 18 вершин. Источник и эталон предоставляются
пользователем локально; геометрические массивы, модели и изображения в Git
не входят. Изменённые байты, другой сценарий и относительные пути отклоняются.
`--config <absolute-config.json>` допускает только точное содержимое этого
сценария: изменение параметров требует отдельной верификации и версии.

CLI сначала проверяет входы, строит решётку и сравнивает упорядоченные грани и
каждую координату с закреплённым эталоном (допуск 1e-12 м). Только затем создаёт
новую папку с `mesh.json` и `report.json`. Существующую папку не использует;
повторный запуск отклоняется. Родительская папка должна существовать. При сбое
записи новая папка может остаться частичной: не принимать её без отчёта и readback.
Локальные выходы содержат геометрию и не предназначены для публикации.

Алгоритм перенесён из собственного `pipe-decor-v002/build.js`; параметры объекта
вынесены в конфигурацию. Исправлена только ошибочная метка зазора: фактические
смещения исходного кода уже были 10.2/130.2 мм, но `parameters.gap` сообщал 10 мм.
Теперь метаданные соответствуют геометрии. Поля `uv`/`front` исходного внутреннего
рецепта не экспортируются: это параметризация построения, не проверенная UV-развёртка.

Изолированные проверки:

```powershell
python -m pytest -q tests/test_pipe_lattice.py
$env:AGR_PIPE_SOURCE = '<absolute-source.json>'
$env:AGR_PIPE_REFERENCE = '<absolute-mesh_gap_allowance.json>'
python -m pytest -q tests/test_pipe_lattice.py
```

Без приватных входов exact-input replay пропускается явно. Синтетические
контрпримеры проверяют запрет перезаписи, конфигурационные изменения и чужие входы.
CLI экспортирует `build(source, config)` для чистого вычисления в памяти;
hash-защита относится к файловому CLI. Внутренний API проверяет форму и конфигурацию.

Историческая native-проверка решётки охватывала counts и 12 контрольных вершин,
а не полный повторный readback координат. Численное QA эталона отдельно проверило
топологию, пересечения и зазор относительно native-источника. Полное открытие
сохранённого MAX и AGR Checker остаются непроверенными; `delivery_passed=false`.
Пользователь принял геометрическую сборку 20.10.2026; текстурный вариант этим
не принят. Код построения 18 отдельных стоек пока не найден и не перенесён:
геометрический JSON-рецепт не заменяет исполняемый builder. Дальнейший шаг —
найти фактически использованный код стойки/массива в исходном чате и проверить
его на тех же приватных входах. Не восстанавливать и не менять активную сцену.
