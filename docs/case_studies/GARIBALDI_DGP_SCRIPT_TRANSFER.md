## Гарибальди: найденное расхождение и исправление

Ранее исходный ZIP ошибочно считался отсутствующим: чтение UTF-8 JSON через Windows
cp1251 искажало кириллический путь. Повторное чтение с явным UTF-8 подтвердило наличие,
CRC и исходный SHA256 `3636eb0c050d9c4c6f2dad9371a2c1348588c8973277c85cc6a5fbeb26c12e23`.
Исторический corrected ZIP действительно отсутствует по recorded path; причину его
отсутствия установить не удалось. Сохранённый final blend совпадает с историческим
`57c337c9e11e570f493d4169c6f40a2f553676c0e2ab84429eb477c67004d205`.

Три собственных скрипта объединены в [один адаптер repair/readback](../../technical_library/sintez_repair/README.md).
Из закреплённого snapshot создаётся новый локальный пакет; исходник не перезаписывается.
Отдельный Blender повторно импортирует FBX/ZIP и запускает native SINTEZ. Новый ZIP
не объявляется побайтным восстановлением исчезнувшего архива. Сверяются шесть точных
mesh/UV/material/transform signatures и 17 packed-texture hashes исходного маршрута.
Код района 0707 относится только к этому объекту и его сохранённому native district check.
Версия addon и все необходимые локальные зависимости проверяются до записи.

Технический результат: устранены ошибки материалов/district; 44 native группы без errors.
28 ручных проверок, УКЭП, пользовательская визуальная приёмка и полная сдача остаются
открытыми. Отсутствие error не равнозначно завершению этих ворот. [Компактный QA](../../technical_library/sintez_repair/QA.json).

## ДГП: текущая версия и воспроизводимые карты

Исторический v5 SHA `41ab35fbd267aa190b92bb35b6c4dd79a3e5ba20df986fa5ba9b2254654e021c`
не совпадает с текущим `8eb2da7fa0c30bc4501635016f0f5310ecb385632b7d5b1c39afd1ff08fb414b`.
Старые байты не найдены; точная причина пересохранения неизвестна. Поэтому старый QA
не переносится молча: выполнено новое чтение текущей v5 и v4 в отдельных 3ds Max 2024.2.5
batch-процессах, без сохранения моделей и без вмешательства в пользовательскую сцену.

Проверенные 16 узлов / 343291 evaluated triangles совпадают по геометрии, UV, face material IDs,
smoothing, transform и именам материалов в точности native числового форматирования.
Только три recorded visibility флага отличаются от v4: 015_MainGlass, 016_Main и
016_MainGlass видимы в v5. Они не исправлялись этим этапом. Explicit normals,
редактируемая polygon-структура, весь shader graph и визуальная приёмка этим сравнением
не доказаны. Все 43 bitmap доступны; изменились только четыре ожидаемых diffuse.
[Новый native QA](../../technical_library/texture_tiles/DGP_NATIVE_QA.json).

Фактически использованная математика сохранена в существующем

Это ресэмплирование предоставленного кирпича, не генератор метрического рисунка;
существующее фасадное ядро не дублируется. Имена файлов, hashes и прямоугольники отделены
в JSON. Повтор на тех же входах совпал со старым маршрутом и сохранённым v5 для всех
43 PNG побайтно и попиксельно: четыре изменённых, 39 неизменных, вне прямоугольника
пиксели сохранены. Масштаб около 25 см предположительный без ВПМ; бесшовность не доказана.
[Pixel QA](../../technical_library/texture_tiles/DGP_QA.json).

## Что принято и что было ошибкой

У ДГП утверждены образцы палитры; Main 002/015/016 сохранены как исключения. Ошибочная
привязка Main 001 в первых отчётах исправлена позже. Ранняя промежуточная приёмка
деревянного декора Main 005 не распространяется на последующие варианты: последнее
уточнение пользователя возвращает исходную раскладку, дерево только на одной обведённой
ступенчатой полосе. Финальная художественная приёмка v5 остаётся открытой. Более поздний
кирпич из атласа коллег относится только к 006/011/012/013. Ранние временные варианты
и ошибочные отчёты сохранены локально, их исполнители не публикуются.

## Защита, воспроизведение и сохранение

Команды, зависимости и новые output-каталоги приведены в README каждого пакета.
Входы привязаны к hashes; существующий output и опасные пути отклоняются. Исключения
не зависят от Python assert/`-O`. Частичный результат при сбое остаётся локальной
диагностикой и не становится прошедшим QA. Ни один исходный/approved файл не заменяется.

В PR входят код, case config, тесты, README и компактные QA. Blender/Max/FBX/PNG/ZIP,
addon, source atlas и подробные private receipts остаются локально. Исходные места
сохранены; новые результаты/readbacks находятся в `tmp/garibaldi-dgp-20261015/`
основной рабочей папки. Никакие временные версии не удалялись. Второй объект и
универсальность workflow не проверены. Независимый reviewer проверяет фактический
код, hashes и отрицательные примеры; hosted CI и merge фиксируются отдельно.
