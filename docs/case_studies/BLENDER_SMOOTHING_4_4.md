# Blender 4.4: очистка Sharp и Smooth by Angle

Источник: чат `01a15321-49e2-7432-af4f-0eabcbb38141`, завершённый этап19.10.2026.
Пользователь просил очистить hard edges и заново добавить Auto Smooth всем объектам.
В исходной сохранённой сцене16локальных mesh без модификаторов. Угол30° выбран
исполнителем; отдельной пользовательской визуальной приёмки нет.

Исходный `shade_auto_smooth` через MCP вернул CANCELLED. Завершение выполнено
через установленный Geometry Nodes asset Smooth by Angle. В библиотеке объединены
очистка custom normals/Sharp, Smooth faces, добавление узла и saved-file readback:
[сценарий](../../technical_library/mesh_audit/SMOOTHING.md).
Это сценарий в существующем mesh_audit, без нового Skill или параллельного topology-аудита.

При свежей проверке20.10 текущий `autosmooth_30deg_v001.blend` отличается от
сохранённого source по vertex coordinates и transforms всех16mesh. Причина
не установлена; исходное утверждение о равенстве нельзя переносить на эту версию.
Сохранённый `.blend1` прошёл исходный проверяющий скрипт: raw/evaluated инварианты
равны. Его использовали только для чтения как исторический reference; ничего
не восстанавливали поверх текущего файла.

Перенесённый маршрут на том же source в новом background Blender4.4 создал
отдельный output и подтвердил равенство историческому reference по геометрии,
UV, material slots, transforms, evaluated Sharp/Smooth и corner normals.
Оба сохранённых файла прочитаны повторно; исходные SHA не изменились.
[Компактное доказательство](../../technical_library/mesh_audit/SMOOTHING_QA.json).

Ограничения: только Blender4.4, явно указанный набор local mesh без прежних
модификаторов, один реальный кейс. Второй проект, визуальная приёмка,
полная topology/UV/AGR-сдача не подтверждены. Код не устанавливает MCP,
не меняет пользовательский config и не подключается к активной сцене.
Модели и полные локальные отчёты остаются вне Git; публикация только draft.
