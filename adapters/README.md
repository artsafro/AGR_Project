# Контракт адаптеров

Ядро не передаёт геометрию через AI-контекст. В этом маленьком примере мост
принимает JSON-массивы; для производственных мешей нужен отдельный файловый формат.

Запрос export содержит: operation, profile, layout, address, абсолютные пути
fbx/blend/atlas/result. Layout содержит XYZ, UV по углам граней, stable surface IDs,
внутренние material IDs, экспортный slot и UDIM tile. Единицы — метры.

Запрос audit содержит: operation, fbx, result. Он открывает только данный файл
в отдельном процессе. Ответ содержит версию приложения, хеш FBX, объекты,
треугольники, world-space координаты, UV, материалы, трансформации и хеши карт.
Успех процесса без результата не является успехом адаптера.

Blender 4.4: реализация в `blender/bridge.py`, выполнены export и повторный import.
Max/Revit/CAD: контракты направления описаны в подкаталогах, исполняемых адаптеров нет.
Наличие установленного приложения не подтверждает интеграцию.
