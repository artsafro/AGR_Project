# Безопасность

Репозиторий закрытый. Не публикуйте сведения об уязвимостях, токены, локальные
пути к закрытым материалам или входные файлы ОКС в публичных каналах.

Сообщайте о проблеме владельцу репозитория через приватный GitHub-канал. В
сообщении укажите затронутую версию или commit, способ воспроизведения, влияние и
минимальный пример без данных заказчика.

Поддерживается только текущий `main`. Автоматические security alerts зависят от
доступных функций GitHub; их отсутствие не означает отсутствие уязвимостей.
